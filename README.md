# Pilk · 여행 사진 포즈 코치

> **KU AI Hackathon · Team 12 (2026)**
> 여행지에서 카메라를 켜면 예시 포즈와 내 자세를 실시간으로 비교해 "어디를 고치면 되는지" 알려주고, 촬영 장소 주변 스팟까지 연결하는 모바일 웹앱입니다. 일본인 여행객을 주 타깃으로 하며 한국어 · 영어 · 일본어를 지원합니다.

- **바로 써보기:** https://kuaiteam12.vercel.app (휴대폰 브라우저 권장, 카메라 권한 허용)
- **GitHub:** https://github.com/kkiihun/KUAI_team12

## 1. 주요 기능

앱은 하단 독의 세 화면으로 구성됩니다: **카메라**, **탐색**, **보관함**.

### 카메라
| 기능 | 설명 |
| --- | --- |
| 실시간 포즈 코칭 | 예시 포즈와 팔·다리·몸통 각도를 비교해 「포즈 일치도」(%)와 교정 문구를 보여줍니다. 예시 포즈는 흰 점선으로 내 몸에 겹쳐 표시됩니다. |
| 여러 명이 있을 때 | 최대 4명을 인식하고 코칭할 한 명을 계속 따라갑니다. 화면을 탭하면 대상을 바꿉니다. |
| 2인 포즈 | 「ひとり / ふたり」 전환. 나란히 걷기는 점수까지 판정하고, 몸이 닿는 하트·등 맞대기는 예시와 안내만 보여줍니다. |
| 카메라 비율 | 16:9(기본) / 4:3 / 1:1. 찍힌 사진도 화면에 보이는 그대로 잘립니다. |
| 설정 메뉴(⚙️) | 자동 켜기, 배경 체크, 가이드 표시/숨김, 촬영 안내 카드, 포즈 가이드와 촬영 옵션(타이머 · 렌즈 · 거리 등), 카메라 설정(AR 가이드 투명도 · 예시 건너뛰기 · 격자 · 테마 색상) |
| 포즈 맞으면 자동 촬영 | ⚙️ → 카메라 설정에서 켭니다(기본 꺼짐). 포즈 일치(모든 부위 25° 이내, 0.7초 유지)가 되면 3·2·1 후 촬영하고, 카운트다운 중 포즈가 흐트러지면 취소합니다. |
| 카메라 켜기 · 전환 | 카메라가 꺼져 있으면 셔터를 눌러 켭니다. 전면 · 후면 전환은 화면 우측 상단(⚙️ 옆) 버튼. |
| 불러오기 | 앨범 사진을 불러와 배경 밝기 · 명암 · 색감을 분석합니다. |
| 음성 안내 | 교정 문구를 한·영·일 음성으로 읽어줍니다. |
| 사진 편집 · 스토리 카드 | 밝기 · 대비 · 채도 · 흐림 · 자르기 · 회전 · 좌우반전 후 저장, 인스타 스토리용 카드(1080×1920) 저장 |
| 배경 체크 | 화면의 밝기 · 명암 · 색감을 기기에서 분석해 촬영 팁을 주고, 현재 위치 10 km 이내 스팟을 추천합니다. |

### 탐색
- 등록된 촬영 스팟 44곳을 지도(Leaflet + OpenStreetMap)와 목록으로 보여주고, 인스타 · 틱톡 · 드라마 · 고궁 · 자연으로 거를 수 있습니다.
- 스팟 근처 미용실(OpenStreetMap 데이터), 모델 모집 공고(`casting-listings.js`에 등록된 공고, 현재 0건 + 검색 링크), 주변 혜택(시연용 **예시** 쿠폰)을 보여줍니다.

### 보관함 · 공통
- 저장한 스팟과 예시 쿠폰, 이용 안내, 사진 출처
- 처음 접속하면 4단계 이용 안내가 뜨고, 상단 「?」로 다시 볼 수 있습니다. 일본어 브라우저는 일본어로 시작합니다.
- 카메라 영상과 사진은 기기 안에서만 처리되며 서버로 전송되지 않습니다.

## 2. AI 활용

| 층위 | 사용한 AI | 역할 |
| --- | --- | --- |
| 제품 안의 AI | **Google MediaPipe Pose Landmarker** (온디바이스 딥러닝, Apache 2.0) | 카메라 영상에서 사람의 관절 33개 위치를 실시간으로 찾습니다. |
| 개발 | **Claude Code** (AI 코딩 도구) | 포즈 비교 알고리즘, 여러 명 추적, UI 구현과 테스트 |
| 디자인 | **GPT** (이미지 생성) | 로고 · 앱 아이콘, 2인 포즈 예시 사진 3장 |

AI 모델은 구글이 학습시킨 것을 그대로 사용하며, 팀이 모델을 학습시키지는 않았습니다. 관절 좌표를 받아 포즈를 비교 · 판정 · 코칭하는 부분은 팀이 만든 알고리즘입니다.

### 포즈 인식이 동작하는 방식 (`pose-tracking.js`)
1. **관절 찾기:** MediaPipe가 프레임마다 최대 4명의 관절 33개를 찾습니다. GPU가 되면 Full 모델, 아니면 CPU + Lite 모델로 자동 전환합니다.
2. **대상 추적:** 이전 프레임의 대상과 영역 겹침(IoU) · 거리 · 크기가 가장 잘 이어지는 사람을 따라갑니다. 다른 사람에게 가려진 관절은 0.45초, 대상 전체는 0.9초 동안 유지합니다.
3. **포즈 비교:** 예시 사진에서 미리 뽑아둔 기준 골격(`pose-templates.js`)과 부위별 방향 각도를 비교합니다. 위치나 키와 상관없이 같은 기준으로 비교되고, 좌우를 뒤집은 포즈도 인정합니다.
4. **판정:** 모든 부위가 25° 이내이고, 예시 부위의 75% 이상이 보이고, 0.7초 이상 유지될 때만 「ぴったり」로 판정합니다(오판 방지).
5. **표시:** 분석한 바로 그 프레임 위에 골격을 그려서, 사람이 움직여도 골격이 몸에서 밀리지 않습니다.

**2인 포즈:** 실시간 모드의 MediaPipe는 처음 잡은 한 사람만 계속 따라가고, 붙어 있는 두 사람을 하나로 합치는 경우가 많습니다. 그래서 2인 모드에서는 화면을 좌우 반쪽으로 나눠 한 명씩 찾습니다. 몸이 닿는 포즈는 누구의 팔다리인지 신뢰할 수 있게 구분되지 않아 점수를 매기지 않습니다.

**검증 범위:** 예시 사진을 가상 카메라 영상으로 넣은 브라우저 테스트에서, 같은 포즈는 94~97점으로 「ぴったり」, 다른 포즈는 26~83점으로 모두 불합격이었습니다. 실제 휴대폰 · 실사용자 테스트는 아직 하지 않았으므로 정확도 수치로 인용하지 마세요.

## 3. 실행 및 배포

### 로컬 실행 (Node.js 18 이상)
```bash
node server.mjs
```
`http://localhost:8005`을 열고 카메라 권한을 허용합니다.

### 휴대폰에서 테스트
휴대폰 브라우저의 카메라는 HTTPS에서만 동작합니다. 로컬 서버를 켠 상태에서 아래를 실행하고, 출력되는 `https://….trycloudflare.com` 주소를 휴대폰에서 엽니다.
```bash
npx --yes cloudflared tunnel --url http://localhost:8005
```

### 배포
Vercel에 저장소 루트를 정적 사이트로 연결해 배포합니다(현재 https://kuaiteam12.vercel.app). 빌드 단계는 없습니다.

├── poses.js                # 포즈 실루엣 가이드 (SVG)
├── casting-listings.js     # 모델 모집 공고 데이터
├── manifest.webmanifest    # 홈 화면 추가용
├── server.mjs              # 로컬 정적 파일 서버

└── assets/
    ├── pose-engine/        # MediaPipe 실행 파일과 모델 (pose-full.task 9.4MB, pose-lite.task 5.8MB)
    ├── poses/              # 포즈 예시 사진
    ├── places/             # 스팟 사진
    ├── brand/              # 로고 · 아이콘 · 파비콘
    └── leaflet/            # 지도 라이브러리
