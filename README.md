# ✳ PILK (Picture It Like Korean)

> **KU AI Hackathon · Team 12 Project (2026)**  
> **한국인처럼 감각적인 인생샷을 실시간으로 코칭하고, 촬영 배경을 인식해 주변 핫플·로컬 혜택까지 연결하는 모바일 포토 웹앱**

---

## 로컬 실행

Node.js 22 이상에서 `node server.mjs`를 실행하고 `http://localhost:8005`를 엽니다.
카메라 탭과 포즈 선택 화면은 촬영 예시를 5초간 보여준 뒤 라이브 카메라를 요청합니다. 처음 이용할 때는 브라우저의 카메라 권한을 허용하세요. 촬영 타이머는 셔터를 누른 뒤에 별도로 동작합니다.

Pilk의 배경 스캔은 화면의 밝기 분포와 중앙·주변 밝기 차이, 색감을 기기에서 분석합니다. 위치 버튼을 누르면 현재 위치를 기준으로 10 km 이내 등록 스팟을 최대 세 곳 제안합니다.

라이브 카메라에서 MediaPipe Tasks Vision 0.10.21 Pose Landmarker가 브라우저 안에서 자세를 추정합니다(GPU 가능 시 Full 모델, 아니면 CPU + Lite 모델로 자동 전환). 모델과 WebAssembly 런타임은 assets/pose-engine에 포함되어 있습니다.

**사람이 겹치는 환경(관광지 인파) 대응** — `pose-tracking.js`
- 한 프레임에서 최대 4명을 검출하고, 코칭 대상 1명을 IoU·중심 거리로 프레임 간 추적합니다. 지나가는 사람이 겹쳐도 대상이 바뀌지 않습니다.
- 여러 명이 보이면 화면을 **탭해서 코칭할 사람을 선택**할 수 있습니다(다른 사람은 점선으로 표시).
- 다른 사람에게 가려진 관절은 0.45초, 대상 전체는 0.9초 동안 마지막 위치를 유지합니다.
- One-Euro 필터로 떨림을 줄이고, 상태 문구는 3프레임 연속일 때만 바꿔 깜빡임을 막습니다.
- 감지 소요 시간에 맞춰 호출 간격을 자동 조절합니다(requestVideoFrameCallback).

**골격과 사람이 정확히 겹치도록(프레임 고정 렌더링)** — 분석한 프레임을 복사해 그 프레임에서 감지하고, 같은 프레임을 골격 아래에 그립니다. 라이브 영상 위에 그리던 이전 방식은 감지 지연(100~200 ms)만큼 골격이 사람보다 늦게 따라왔습니다.

**포즈 추천(예시 포즈 비교)** — `pose-templates.js`에 예시 사진(`assets/poses`)에서 추출한 기준 골격이 있습니다. 팔·다리·몸통·고개의 방향 각도를 비교하므로 서 있는 위치나 크기와 무관하게 「韓国っぽ度」 점수와 교정 문구(예: 「画面右のひじから先を少し下げて」)를 줍니다. 기준 포즈는 사용자의 몸통에 맞춰 흰 점선(고스트)으로 겹쳐 그리고, 가장 어긋난 부위를 빨갛게 강조합니다. 좌우 반전된 포즈도 인식합니다. (전신·振り返り·鏡越し·ほっぺツン 4종 지원, 真上ショット·猫の影는 기존 가이드 유지)

**로고** — `assets/brand/`에 원본(`pilk-logo-original.webp`)과, 배경을 투명하게 딴 로고·심볼·워드마크 PNG, 앱 아이콘(192/512), apple-touch-icon, 파비콘이 있습니다. 어두운 배경용으로 흰 글자 버전(`pilk-logo-dark.png`, `pilk-wordmark-white.png`)도 있습니다. 홈 화면 추가용 `manifest.webmanifest`도 포함합니다.

**테마 색상** — 보관함 설정에서 핑크(기본) / 블루 / 다크를 고를 수 있고 선택은 기억됩니다. 다크에서는 흰 글자 로고로 바뀝니다.

**이용 안내** — 처음 접속하면 4단계 사용법(포즈 고르기 → 카메라 비추기 → 사람이 많을 땐 탭 → 찍고 공유)이 자동으로 뜨고, 상단 「?」 버튼이나 보관함의 「使い方」에서 다시 볼 수 있습니다.

**가이드 숨기기 / 바로 카메라** — 뷰파인더의 👁 버튼으로 골격 가이드를 숨길 수 있습니다(숨겨도 점수·문구는 계속 동작, 얼굴에는 점을 찍지 않음). 예시 포즈 화면의 「すぐ撮る」 버튼이나 보관함 설정 「お手本をとばしてすぐカメラを起動」으로 예시 없이 바로 카메라를 켤 수 있습니다.

**일본 사용자 친화 UI** — 밀크 핑크 파스텔 테마, 일본어 둥근 고딕(Zen Maru Gothic), 자연스러운 일본어 카피(「真上ショット」「全身スタイルアップ」「サロンモデル募集」 등), 「韓国っぽ度」 하트 미터, 포즈 인기 배지, 폴라로이드형 스토리 카드, 브라우저 언어 자동 감지(일본어 브라우저는 JP로 시작).

사진 편집과 타이머는 브라우저에서 동작합니다. 밝기·대비·채도·흐림·자르기·90도 회전·좌우반전을 조절해 JPEG로 저장할 수 있습니다.

탐색의 모델 모집 탭은 `v005/casting-listings.js`에 등록된 해당 지역의 유효 공고와 원문 지원 링크를 표시합니다. 지역별 모집 검색도 사용할 수 있습니다.

이에 **`v005`에서는 한복 중심 구조에서 과감히 피벗**하여, 방한 외국인 90%+가 일상복으로 즐기는 **「한국인처럼 감각적으로 사진 찍는 법(항공샷 · 발끝 정렬 · 앞발 빼기 · 거리 코칭)」**과 **「촬영 배경 자동 인식 → 주변 관광지·지도·로컬 제휴 추천」**을 결합한 **카메라-퍼스트 모바일 웹앱**으로 재구성했습니다.

> 상세한 멘토 Q&A 및 수익 모델·시장 분석은 [`v005/MENTOR_FEEDBACK_AND_STRATEGY.md`](v005/MENTOR_FEEDBACK_AND_STRATEGY.md)에서 확인할 수 있습니다.

## 2. 주요 기능 (`v005` 최신 기준)

**세 개의 탭(`카메라` · `탐색` · `보관함`)**로 구성되어 있습니다.

### 📷 1) `카메라` 탭 — 실시간 한국식 포토 디렉터
- **실시간 WebRTC 카메라 + 전면/후면 전환**: 후면(`environment`) ↔ 전면 셀카(`user`) 전환 및 셀카 미러링 촬영 지원
- **실시간 한국식 구도 코칭 & K-Match(%)**:
  - 6종 한국 트렌드 포즈 AR 실루엣 오버레이 (`항공샷`, `전신 비율`, `뒤돌아보기`, `거울셀카`, `고양이그림자`, `볼콕`)
  - 1줄 퀵 컨트롤: `AR / 3단계 / 음성` 모드 전환(카메라 스트림 유지), `항공샷(? 가이드 모달 포함)`, `앞발`, `0.5× / 1× / 2×`, 거리 시뮬레이터(`뒤로 / 최적 / 앞으로`), 모바일 자이로 수평계(`DeviceOrientationEvent`)
- **모바일 음성 코칭**: Web Audio API 세션 언락 + `Web Speech API` 다국어(`ko-KR / en-US / ja-JP`) 음성 안내
- **찍어주는 사람용 10초 카드 (`👥`)**: 친구·연인·행인에게 보여주면 10초 만에 원하는 구도로 찍어줄 수 있는 대형 가이드 카드
- **사진 저장 & 인스타 스토리 카드(`1080×1920 PNG`)**: 촬영 컷을 즉시 기기에 저장하거나 인스타그램 스토리 규격 카드로 원클릭 내보내기

### 📍 2) `주변` 탭 — AI 배경 스캔 · 인터랙티브 지도 · 로컬 추천
- **배경 자동 분석 (`Canvas`)**: 현재 카메라 화면 또는 업로드한 사진의 밝기·색감(자연광/야간 등)을 로컬 분석해 최적 촬영 세팅 제안
- **인터랙티브 구글 지도 임베드**: 현재 스팟 및 추천 장소별 위치를 탭 내에서 바로 확대·확인하고 구글 지도 앱 길찾기로 연결
- **주변 관광지 & 로컬 제휴 쿠폰(`[예시]`)**: 도보 거리별 카페·팝업·명소 추천 및 시연용 예시 쿠폰 발급/저장

### 🔍 3) `스팟` 탭 — 한국 SNS 스팟 44곳 탐색
- **SNS 중심 카테고리 필터**: `전체(44)` · **`인스타(15)`** · **`틱톡(12)`** · `드라마(11)` · `고궁(13)` · `자연(11)`
- 한/영/일 3개 국어 통합 검색, 북마크, 스팟 사진 1탭으로 `카메라` 탭 배경 즉시 로드

### 🔖 4) `보관함` 탭 — 쿠폰 · 스팟 · 카메라 설정
- 발급받은 예시 쿠폰 및 저장한 스팟 관리 (`localStorage` 로컬 보관)
- AR 가이드 투명도 슬라이더, 발끝선·3분할 격자 표시 설정, 사진 출처 안내

## 6. 실행 및 배포 방법

### 1) 로컬 실행 (Node.js 18+)
```bash
node server.mjs
```

### 2) 휴대폰에서 실시간 카메라 테스트 (HTTPS 터널)
모바일 브라우저에서 실시간 카메라(`WebRTC`)와 자이로 센서는 HTTPS 환경이 필요합니다.
```bash
npx --yes cloudflared tunnel --url http://localhost:8005
```
출력되는 `https://*.trycloudflare.com` 주소를 휴대폰 Safari/Chrome에서 열면 즉시 테스트할 수 있습니다.

### 3) 상시 배포 (Vercel 추천)
1. Vercel에서 본 GitHub 저장소를 Import하고 **Root Directory를 `v005`**로 지정합니다.
2. 정적 사이트로 배포합니다.
